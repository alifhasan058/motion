# TWO 26 — Creative Studio

Static website for the independent design studio TWO 26. Built from the Linen "Creative Studio" design spec.

## Views (hash routing, single `index.html`)
- `#home` — landing: hero, our story, selected work, services, process, CTA
- `#studio` — about the studio
- `#work/brew-crew` — Brew Crew project detail
- `#contact` — inquiry form, studio contact, business hours

## Run
Open `index.html` in a browser, or serve the folder (`npx serve .`). Works on GitHub Pages as-is.

## Stack
Vanilla HTML, CSS and JavaScript. Fonts: Anton, Archivo, Inter, Caveat, Montserrat (Google Fonts). Illustrations are `.webp` files in the repo root.
